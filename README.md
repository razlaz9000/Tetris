# Blockfall

A mobile-first falling-block puzzle game in a single `index.html` — no build step, no dependencies.

## Play
- Open `index.html` in any browser, or enable GitHub Pages (Settings → Pages → deploy from this branch) and open the URL on your phone.
- On iOS/Android, "Add to Home Screen" gives a full-screen app feel.

## Controls
| Touch | Buttons | Keyboard |
|---|---|---|
| Tap board: rotate | ↻ | ↑ / X (Z = counter-clockwise) |
| Drag sideways: move | ← → (hold to repeat) | ← → |
| Drag down: soft drop | ↓ | ↓ |
| Flick down: hard drop | ⤓ | Space |
| Flick up / tap Hold box: hold | — | C / Shift |
| — | ❚❚ | P / Esc: pause |

## Features
7-piece bag randomizer, SRS rotation with wall kicks, ghost piece, hold, 3-piece preview, lock delay, levels every 10 lines, best score saved locally, haptics where supported, auto-pause when backgrounded.
